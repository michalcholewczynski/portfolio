# Lokalne fonty

Katalog zawiera lokalne podzbiory fontów używanych na stronie:

- DM Sans — `dm-sans.woff2` (Latin Extended) i `dm-sans-latin.woff2` (Latin)
- DM Mono — `dm-mono.woff2` (Latin Extended) i `dm-mono-latin.woff2` (Latin)

Fonty są dystrybuowane na licencji SIL Open Font License 1.1. Pełne teksty
licencji znajdują się w plikach `OFL-DM-Sans.txt` i `OFL.txt`.

Źródła fontów:

- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/dmmono
